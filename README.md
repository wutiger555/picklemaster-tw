## 🎯 專案簡介

**匹克大師台灣（Picklemaster Taiwan）** 是專為台灣匹克球愛好者打造的一站式學習與資源平台。

<table>
<tr>
<td width="50%">

### ✨ 核心亮點

🗺️ **全台 125+ 球場地圖**  
涵蓋台北、台中、高雄、台南等全台各縣市

🏆 **2026 賽事總覽**  
CTPF 認證全年賽事、國際積分賽、分齡賽一次看

📖 **術語字典 + DUPR 評級**  
中英對照匹克球權威字典、2026 全球通用評分系統

🎮 **3D 互動學習**
360° 球場、戰術板、球路模擬一次到位

</td>
<td width="50%">

### 🚀 特色功能

🏸 **裝備選購指南**
球拍完全指南 + AI 智能推薦系統

📖 **系統化學習路徑**
從新手入門到進階技巧的完整路線

⚡ **互動式遊戲**
實作完整匹克球規則的網頁遊戲

</td>

## 🎨 核心功能

### 🗺️ 全台球場地圖
<details>
<summary>點擊展開詳細功能</summary>

- ✅ 超過 **55 個球場**資訊，持續更新中
- 🗺️ 互動式地圖標示球場位置
- 🔍 篩選功能：依地區、室內/室外、收費/免費分類
- 📍 球場詳細資訊：地址、開放時間、設施狀況
- 🧭 一鍵導航至球場

</details>

### 📚 規則教學
<details>
<summary>點擊展開詳細功能</summary>

- 🎯 **互動式球場**：點擊不同區域即時顯示規則說明
- 🎮 **3D 球場配置**：360° 旋轉檢視，學習站位與規則
- ⚡ **戰術板演示**：全新升級版！精準模擬 Cross-court 發球與 Third Shot Drop 落點

</details>

### 🎥 影音教學
<details>
<summary>點擊展開詳細功能</summary>

- 🎬 **高畫質示範**：慢動作解析關鍵動作（如大陸式握拍、正手擊球）
- 📱 **視覺化學習**：首頁精選影片預覽，沉浸式學習體驗
- ⚡ **極速載入**：優化影片載入效能，支援隨點隨播

</details>

### 🏸 裝備指南
<details>
<summary>點擊展開詳細功能</summary>

- 📖 **球拍完全指南**：材質、重量、平衡點、握把尺寸完整解析
- 🏆 **職業選手裝備**：頂尖選手使用的球拍型號與規格
- 🤖 **AI 智能推薦系統**：根據技術程度、打法風格、預算推薦適合球拍

</details>

### 🏆 頂尖選手 (Pro Players)
<details>
<summary>點擊展開詳細功能</summary>

- 🌟 **互動式球員卡**：3D 懸浮設計，展示選手英姿
- 📊 **戰力分析雷達**：力量、控制、速度數值化呈現
- 🏸 **御用裝備揭密**：一鍵查看 Ben Johns、ALW 等冠軍選手使用球拍
- ✨ **動態視覺特效**：高質感粒子與光影效果，打造名人堂氛圍

</details>

### 📖 學習路徑
<details>
<summary>點擊展開詳細功能</summary>

|    等級    | 內容                         | 適合對象     |
| :--------: | :--------------------------- | :----------- |
| 🌱 **新手** | 基礎規則、握拍姿勢、發球技巧 | 完全初學者   |
| 🌿 **中階** | 網前技術、雙打配合、戰術應用 | 有基礎經驗者 |
| 🌳 **進階** | 高階技巧、比賽策略、心理素質 | 競賽級玩家   |

- 💾 **進度追蹤**：自動儲存學習進度（LocalStorage）

</details>

### 🎮 互動遊戲 (Pickle Master)
<details>
<summary>點擊展開詳細功能</summary>

- 🎯 **第一人稱射擊 (FPS) 視角**：擬真視角體驗，如身臨其境般的擊球快感
- 🔥 **必殺技系統**：累積專注值擊出「火焰球」，以及隨機觸發的「幸運一擊」
- ⚡ **極簡操作**：單鍵蓄力擊球，智慧自動跑位，專注於戰術與時機
- ⚙️ **真實規則實作**：完整包含換發球制 (Side-Out)、廚房規則 (Kitchen)、雙跳規則 (Two-Bounce)
- 🏆 **街機風格體驗**：動態鏡頭縮放、打擊震動回饋，讓匹克球更刺激有趣

</details>

### 📱 資源中心
<details>

## 💻 本機開發

### 📋 環境需求
- ![Node.js](https://img.shields.io/badge/Node.js-18+-339933?style=flat-square&logo=node.js&logoColor=white) **Node.js** 18 或以上版本
- ![npm](https://img.shields.io/badge/npm-latest-CB3837?style=flat-square&logo=npm&logoColor=white) **npm** 或 **yarn** 套件管理工具

### 🚀 快速開始

```bash
# 1️⃣ 複製專案
git clone https://github.com/wutiger555/picklemaster-tw.git
cd picklemaster-tw

# 2️⃣ 安裝依賴套件
npm install

# 3️⃣ 啟動開發伺服器（支援熱更新）
npm run dev

# 4️⃣ 開啟瀏覽器訪問
# 🌐 http://localhost:5173
```

### ⚙️ 可用指令

| 指令              | 說明                          | 圖示  |
| :---------------- | :---------------------------- | :---: |
| `npm run dev`     | 啟動開發伺服器（Vite 熱更新） |   ⚡   |
| `npm run build`   | 建置生產版本至 docs/ 目錄     |   📦   |
| `npm run preview` | 預覽建置結果                  |   👀   |
| `npm run lint`    | 執行 ESLint 程式碼檢查        |   🔍   |

## 🔧 維護指南

### 添加新球場
1. 打開 `src/data/courtsData.ts` (或 `public/data/courts.json`)
2. 按照現有 JSON 格式添加新的球場物件
3. 提交變更，地圖將自動更新

### 更新新聞
1. 編輯 `src/data/newsData.ts`
2. 依照 `NewsItem` 介面新增新聞條目
3. 圖片請放置於 `public/images/news/`

### SEO 配置更新
1. 編輯 `src/utils/seo.ts`
2. 針對特定頁面修改 title 或 description
