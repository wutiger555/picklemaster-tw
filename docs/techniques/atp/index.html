ATP 繞網柱球（Around The Post）

Around The Post · 進階 · 擊球 · 難度 5/5 · 學習時間約 需要機會 + 技術，非「每天可練」

不過網、繞柱而擊

什麼時候用

對方把球打到你的邊線外側時，你不用越網，而從球柱的「外側」水平擊球繞過網柱回擊。

關鍵要點

  • 球必須從網柱外側繞過（合法）
  • 擊球時不能碰網柱
  • 軌跡呈水平弧線而非拋物線
  • 機會罕見但一旦出現就是 winner
  • 對方送邊線球時最常出現

步驟分解

  1. 1. 識別機會：對方球路偏向你的邊線外、且落地時已低於網高度時。這是唯一的 ATP 時機。
  2. 2. 跑向球柱外側：快速橫移到球柱外側下方，身體完全在球柱外。
  3. 3. 低位側擊：拍面水平、從側面掃擊球。球軌跡平行於地面，繞過網柱飛向對方場地。
  4. 4. 瞄準空場：由於球不越網，對方完全無法防守網前。目標是對方場地的空檔處。

常見錯誤與修正

  • 球碰到網柱 = 失分：練習時留意球柱高度，確保球路低於柱頂。
  • 球跨回網上方（違規）：ATP 必須是「水平繞過」，只要球的任何部分跨越網頂就算違規。
  • 想打 ATP 但時機不對：只有對方球明顯打到邊線外、且低於網高度時才有機會。強求只會失誤。

練習菜單

  • ATP 機會識別（每週 2 場）：觀看比賽時專注記錄 ATP 嘗試，理解其時機。
  • 餵球 ATP（20 球 / 天）：搭檔故意將球餵到邊線外且低矮，專門練習 ATP。

進階心法

ATP 規則常見誤解：許多人以為球要從網柱外側飛回時「不能超過網高度」，這是錯的。規則只要求球不從「網上方越過」，球柱外側繞行時可以比網還高。
