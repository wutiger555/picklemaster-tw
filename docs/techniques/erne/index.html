ERNE 繞邊跳擊（Erne）

Erne · 進階 · 網前 · 難度 5/5 · 學習時間約 3-6 個月

匹克球最帥的進階技巧

什麼時候用

對方準備打邊線軟球時，你快速繞到廚房區外側（邊線外）跳起截擊。合法且極具威脅。

關鍵要點

  • 必須跳離廚房區（落地點在廚房外側）
  • 判斷對方軟球傾向是關鍵
  • 時機比動作更重要
  • 失敗率高，只在高機率時機使用
  • 常搭配搭檔的偷球喊話

步驟分解

  1. 1. 預判對方路線：當對方引拍時判斷是否會打直線邊線軟球。這是 Erne 的前提。
  2. 2. 快速橫移：從廚房線位置向邊線外側橫移 2-3 步，完全離開廚房區範圍。
  3. 3. 跳起截擊：在邊線外側的廚房邊區跳起，空中截擊對方來球。
  4. 4. 落地避開廚房：這是最難的部分！落地時必須在廚房區外，否則違規失分。
  5. 5. 擊球方向：通常打向對方兩位球員中間的空隙（最難回擊的位置）。

常見錯誤與修正

  • 落地踩進廚房：跳起前就確保起跳點和落地點都在廚房區外。
  • 時機不對被反擊：Erne 成功率低時不要硬做。高成功率時機：對方重複打同一路線的軟球。
  • 擊球方向被防守到：練習瞄準「兩人中間」或「非截擊方的弱邊」，而非打到空場。

練習菜單

  • Erne 機會識別（每週 1 場）：觀看職業比賽錄影，記錄每次 Erne 嘗試的時機與結果。
  • 邊線橫移爆發力（20 次 × 3 組）：從廚房線快速橫移到邊線外，計時。目標 1.5 秒內到位。

進階心法

Erne 的「替代版」是 Bert — 從網的另一側跳起截擊對方球。Erne 打直線邊線球、Bert 打交叉球。兩者都是炫技但實用的進階武器。
