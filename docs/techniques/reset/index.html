重置球（Reset）

Reset · 中階 · 防守 · 難度 4/5 · 學習時間約 1-2 個月

被強攻？用軟球穩住戰局

什麼時候用

對方連續強攻、你被打到後退或蹲下時。用軟球中止對方節奏，重新建立對戰。

關鍵要點

  • 目的是「中止對方進攻」，不是得分
  • 球路低、軟、落在對方廚房
  • 蹲得越低越容易成功
  • 拍面向上開放 30-45 度
  • 不要硬擋，要「吸收」球速

步驟分解

  1. 1. 降低重心：被快速球壓制時，膝蓋大幅彎曲，身體蹲低到球以下。
  2. 2. 鬆握拍：把握力減到最鬆（2-3 分力）。想像用海綿接球而非鋼板。
  3. 3. 拍面開放迎球：拍面向上開約 40 度，像用勺子接球。
  4. 4. 吸收 + 推送：球碰到拍面時手臂略微後退吸收動能，然後輕輕往前推送回對方廚房。
  5. 5. 恢復站位：reset 成功後立刻上網，重新進入廚房對戰節奏。

常見錯誤與修正

  • 硬擋造成機會球彈回：鬆握、吸收是關鍵。心態從「對抗」切換到「讓步」。
  • 球太高 → 對方再扣殺：降低身體，拍面從下往上送，而非平擋。
  • 只想攻、不想 reset：心理建設：reset 不是認輸，是高手必備的第五檔。

練習菜單

  • 被打 reset 訓練（50 球 × 3 組）：搭檔從網前快速下壓球，你專門練 reset 回軟球。
  • 蹲姿強化（10 組）：保持半蹲姿勢 30 秒，訓練下肢耐力（reset 很靠下肢）。

進階心法

Reset 是從中階（DUPR 3.5）升到進階（4.0+）最大的門檻。世界頂尖選手 Riley Newman、Ben Johns 等人的 reset 成功率超過 85%，是他們難以擊敗的核心原因。
