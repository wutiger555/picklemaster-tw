第三球下切（Third Shot Drop）

Third Shot Drop · 中階 · 擊球 · 難度 4/5 · 學習時間約 2-3 個月穩定

從中階升級到進階的關鍵一球

什麼時候用

你是發球方、已發完球並接到對方回擊（即第三球），對方已站上網前。用第三球下切扭轉開局劣勢，跟上網前。

關鍵要點

  • 目標落點：對方廚房區（NVZ）
  • 弧線高、速度慢（像高拋物線）
  • 從底線打到網前約 12 公尺
  • 成功後要立刻跟上到網前
  • 不求得分，只求過渡
  • 失敗率接受 30-40%，重點是「大多時候能進」

步驟分解

  1. 1. 判斷時機：對方回球落在你半場後半時優先選 drop；若球短、彈起太高，可改打 drive（強攻球）。
  2. 2. 下蹲取球：膝蓋大幅彎曲，讓拍面從低位取球。身體重心降到球以下。
  3. 3. 開放拍面：拍面向上打開約 30-45 度，像用勺子把球「舀」起來。
  4. 4. 慢速推送：從後到前緩慢推送，完全不發力。想像在「放下」一顆球，而非「打」。
  5. 5. 立刻上網：擊球後不要停留看結果，立刻小步快跑到廚房線。跟上的速度決定這一分的勝負。

常見錯誤與修正

  • 球太高、變成對手的扣殺禮物：降低拍面角度、減慢速度。弧線最高點應在球網前 1-2 公尺。
  • 球不夠深，自己還在底線：目標落點是對方廚房區內最深處（最靠網面但還在廚房內）。
  • 打完停在原地：打完就跑，跑得比球慢沒關係，重點是你有移動。
  • 用力揮、當抽球打：Drop 是「托、放」而不是「打」。用腿和肩膀的重心轉移，手臂幾乎不動。

練習菜單

  • 底線 drop 到網前（50 顆 × 3 組）：一人站底線打 drop，另一人站廚房線回軟球。專注讓每球都落在廚房內。
  • 移動式 drop（連續 20 回合）：打完 drop 後立刻跑到網前，搭檔會繼續回球，雙方形成廚房對戰。
  • 弧線目標練習（100 顆 / 天）：在對方廚房內放置大浴巾當目標，專門瞄準落點。

進階心法

頂尖選手（DUPR 5.5+）的第三球成功率約 70-75%。中階球員能達到 50% 就已經是非常好的水準。不要對自己太嚴格，重點是願意嘗試、而非只會 drive（強攻）。
